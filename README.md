# Buss It BBQ

Take-out BBQ joint based in Belle Glade, Florida. Pre-launch site to build hype, capture early followers, and start booking catering.

**Tagline:** "Slow Smoked. Real BBQ. Real Florida."

## Pages

- `index.html` — Hero, menu preview, story, catering CTA, opening-soon email capture
- `menu.html` — Full take-out menu (meats, plates, sandwiches, sides, family packs, sweets)
- `catering.html` — 3-tier catering packages + quote form
- `contact.html` — Address, phone, hours, service area, contact form

## Tech

Pure HTML/CSS/JS, no build step. GitHub Pages.

## Before Launch — Swap Placeholders

Find-replace across `.html` files:

| Placeholder | Replace With |
|---|---|
| `[PHONE]` | Real phone |
| `[ADDRESS]` | Street address |
| `[EMAIL]` | Business email |

Forms currently show a fake success state. Wire up via **Formspree** or **Web3Forms** by replacing `<form data-placeholder-form>` with `action="https://formspree.io/f/YOUR_ID" method="POST"`.
